# 📂 Projetos
💬 Chat
Aplicação de chat em tempo real usando Flask + Flask-SocketIO. Vários usuários na mesma rede podem trocar mensagens instantaneamente.

🤖 IA • Score de Crédito
Sistema de análise preditiva para um banco, classificando clientes com base no score de crédito, ajudando a determinar quem pode receber crédito ou empréstimos.

🎨 UI • Login
Página de login moderna e responsiva, com campos de e‑mail/usuário e senha, botão de acesso, link “Esqueci a senha” e rodapé minimalista com políticas.

📊 Dashboard • Vendas
Projeto de análise e dashboard interativo. A partir de uma planilha, apresenta indicadores de receita, desempenho por vendedor e produto, além de comparação de metas x resultados.

🕹️ Game • Newton
Jogo em estilo pixel art inspirado na lenda de Newton. Colete maçãs, some pontos e enfrente dificuldade progressiva.
